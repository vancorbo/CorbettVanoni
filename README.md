ADD ARTWORK
Put the image in the appropriate folder, then add an entry to js/artwork.js.
Year is optional.

Without year:
{title:"Figure Study",medium:"Drawing",image:"images/fine-art/figure-study.jpg"}

With year:
{title:"Self Portrait",year:"2026",medium:"Oil on canvas",image:"images/fine-art/self-portrait.jpg"}

The site will not display "undefined" when year is omitted.
